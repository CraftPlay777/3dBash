# 3dBash

A small Android-ready 3D playground made with Godot 4.

## Included
- Procedurally assembled 3D character
- Third-person follow camera
- Touch joystick
- Large grassy floor, sky, sunlight and landmark pillars
- Android export workflow in GitHub Actions

## Build APK with GitHub Actions
1. Create an empty GitHub repository named `3dBash`.
2. Upload/push these project files to its `main` branch.
3. Open **Actions** and select **Build 3dBash Android APK**.
4. Wait for the workflow to finish successfully.
5. Open the workflow run and download artifact **3dBash-Android-APK**.

## Local run
Open the folder in Godot 4.3 or newer, press Play (F6/F5).

## Controls
Use the on-screen joystick in the bottom-left area to walk around.
